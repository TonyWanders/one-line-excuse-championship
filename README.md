A program that writes one excuse line to `/output/entry.txt`, for the
make.fun competition
[The One-Line Excuse Championship](https://make.fun/bounty/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e).

Run it with Python 3:

```
python3 main.py
```

It writes the excuse below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The excuse is 94 characters, inside the 1 to 140 gate.

## The excuse

```
I invented the answer because the truth was still downloading and I did not want to look idle.
```
